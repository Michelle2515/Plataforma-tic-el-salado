# Plataforma TIC - Barrio El Salado

## Descripción
Este proyecto tiene como objetivo desarrollar una plataforma digital que permita la alfabetización en Tecnologías de la Información y la Comunicación (TIC) para la comunidad del barrio El Salado en Cúcuta.

## Problema
En la comunidad existe una baja apropiación de las TIC, lo que limita el acceso a oportunidades educativas, laborales y sociales.

## Solución
Se propone una plataforma digital interactiva que permita a los usuarios acceder a contenidos educativos, fortaleciendo sus competencias digitales.

## Funcionalidades
- Registro de usuarios
- Acceso a cursos
- Contenido educativo
- Actividades básicas

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
